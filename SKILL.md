# UI/UX Pro Max

AI-powered design intelligence toolkit providing searchable databases of UI styles, color palettes, font pairings, chart types, and UX guidelines.

## What it does

- 67 UI styles (glassmorphism, minimalism, brutalism, etc.)
- 161 color palettes by product type
- 57 font pairings with Google Fonts imports
- 99 UX guidelines and anti-patterns
- 25 chart types with library recommendations
- Support for 15+ tech stacks (React, Next.js, Tailwind, Vue, Svelte, Flutter, SwiftUI, etc.)

## Usage

Search by domain:
- `style` - UI style recommendations + CSS keywords
- `color` - Color palettes by product type
- `typography` - Font pairings
- `ux` - Best practices and anti-patterns
- `chart` - Chart types and libraries
- `landing` - Page structure and CTA strategies
- `product` - Product type recommendations

## Install

```bash
npx uipro-cli init --ai claude
```
